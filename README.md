# Лабораторные работы по машинной арифметике и вычислениям

Решения лабораторных работ, вариант 2, на Python с использованием NumPy.
Для каждой работы подготовлены программа, исходное задание, отчёт
и пояснения для подготовки к защите.

## Структура репозитория

Каждая лабораторная находится в отдельной ветке.
В `main` размещено только это описание.

| Ветка | Содержание |
|---|---|
| [lab-3](https://github.com/molokoedovmp/match-calc/tree/lab-3) | Лабораторная № 3: специальные значения чисел с плавающей точкой, сравнения и округление |
| [lab-4](https://github.com/molokoedovmp/match-calc/tree/lab-4) | Лабораторная № 4: операции с дробями по одному модулю и обращение матрицы Гильберта |

## Как открыть нужную работу

Выберите ветку `lab-3` или `lab-4` в переключателе веток GitHub
либо перейдите по ссылке в таблице.

Чтобы скачать одну работу через Git, например лабораторную № 4:

```bash
git clone --branch lab-4 --single-branch https://github.com/molokoedovmp/match-calc.git
cd match-calc
python -m pip install -r requirements.txt
python lab4_variant2.py
```

Для лабораторной № 3 используйте ветку `lab-3` и файл `lab3_variant2.py`.
В Windows вместо `python` можно использовать `py`.

Подробные инструкции и объяснения находятся в соответствующих ветках.
