# Лабораторная работа № 3 — вариант 2

Специальные значения чисел с плавающей точкой и особенности округления.

Программа исследует операции с `inf`, `NaN`, положительным и отрицательным
нулём, а также сравнение чисел и результатов умножения в одинарной точности.

## Запуск

Требуются Python 3 и NumPy. В терминале из папки с файлами:

```bash
python -m pip install -r requirements.txt
python lab3_variant2.py
```

В Windows вместо `python` можно использовать `py`.
